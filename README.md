# Algorythms_Theory_Lab_2

Программа для автоматизации расчета расхода ткани и итоговой себестоимости пошива швейных изделий (пиджак, брюки, костюм-тройка) по Варианту №7.

## Описание
Проект представляет собой MVP с консольным пользовательским интерфейсом. Расчет расхода ткани масштабируется относительно базового 48 размера. Итоговая стоимость складывается из цены метража ткани, базовой фурнитуры и фиксированной стоимости работы мастеров. Программа поддерживает экспорт данных в формат `.xlsx`.
